========================================
 Class Memo - 班级备忘录
 版本 v1.2 | 纯 JS，零原生依赖 | 轻量易部署
========================================

一个给班级/团队用的在线作业备忘录 Web 应用：
学科作业卡片、富文本编辑、多级权限、历史归档、实时同步、
公告栏、倒计时、作业统计、深色模式、PWA。

------------------------------------------------
功能特性
------------------------------------------------
- 学科卡片：12 个学科（语文/数学/英语/物理/化学/生物/地理/政治/历史/艺术/信息/心理），一行三个
- 日期自动切换：每天 8:00 前显示"昨天"的备忘录，8:00 后切到当天空白页；历史按日期归档可回看
- "昨日备忘录"标记：展示的是昨天内容时自动标注
- 富文本编辑：文字颜色、高亮、1.~5. 序号快捷插入（sanitize-html 白名单消毒，防 XSS）
- 个人完成勾选：作业做完打勾，今日进度条（仅存本机浏览器，按账号隔离）
- 多级权限：超级管理员 / 管理员 / 普通用户，职位自动定级、有名额限制
- 实时同步：WebSocket 广播，有人保存作业时其它在线页面提示刷新
- 后台管理：用户管理（创建/重置/设权限）、学期设置、操作日志
- 学期进度：按开学日/学年末自动计算"第几周第几天（合计天数）· 总天数 · 进度%"
- 深色模式 + 动效 UI
- 密码 bcrypt 哈希存储；会话 Cookie 认证；自助改密（改后他端下线）

------------------------------------------------
技术栈
------------------------------------------------
- 后端：Node.js + Express
- 存储：纯 JS JSON 文件存储（data/store.json，零原生依赖）
- 实时：ws (WebSocket)
- 前端：原生 HTML/CSS/JS（无框架无构建）
- 密码：bcryptjs

------------------------------------------------
快速开始（需要 Node.js >= 18）
------------------------------------------------
1) 安装依赖
   npm install

2) 准备学生名单
   cp students.json.example students.json
   编辑 students.json，格式：
   [ { "name": "张三", "studentId": "01" }, ... ]

3) 批量生成账号（姓名拼音首字母+学号，随机8位密码）
   node seed.js
   结果写入 accounts.txt（姓名/账号/密码）

4) 启动
   npm start
   访问 http://localhost:3000

账号命名规则：姓名拼音首字母(小写)+学号，如"张小明"+08 => zxm08。

------------------------------------------------
配置（环境变量）
------------------------------------------------
PORT          默认 3000    监听端口
SESSION_SECRET            会话签名密钥，生产务必改随机串
DB_PATH       默认 ./data/store.json
SESSION_DAYS  默认 7       会话有效期(天)

------------------------------------------------
职位与权限
------------------------------------------------
班主任 / 电教委员  限额各1  超级管理员（全部权限）
班长              限额2    管理员
团支书/学习委员/各科课代表   管理员
我不是以上职位    无限      普通用户（仅查看）

------------------------------------------------
部署
------------------------------------------------
单 Node 进程 + 静态文件。建议 Nginx 反代到 127.0.0.1:3000，
并加 /ws 的 WebSocket 转发（Upgrade/Connection 头）以启用实时同步。
进程守护可用 PM2 / systemd。生产务必设置 SESSION_SECRET，建议 HTTPS。

------------------------------------------------
安全说明
------------------------------------------------
- 密码 bcrypt 哈希存储
- 富文本 sanitize-html 白名单消毒防 XSS
- students.json / accounts.txt / data/ 已被 .gitignore 忽略，请勿提交真实名单与账号

# 📝 Class Memo — 班级备忘录

一个给班级/团队用的**在线作业备忘录** Web 应用：学科作业卡片、富文本编辑、多级权限、历史归档、实时同步、公告栏、倒计时、作业统计、深色模式、PWA。

**版本 v1.1** · 纯 JS，零原生依赖 · 轻量易部署

---

## ✨ 功能特性

- 📚 **学科卡片**：12 个学科（语文/数学/英语/物理/化学/生物/地理/政治/历史/艺术/信息/心理），一行三个，默认留空
- 📅 **日期自动切换**：每天 8:00 前显示「昨天」的备忘录，8:00 后自动切到当天空白页；历史记录按日期归档，可翻页/选日期回看
- 🏷️ **"昨日备忘录"标记**：当展示的是昨天内容时自动标注
- 🎨 **富文本编辑**：文字颜色、高亮、`1.`~`5.` 序号快捷插入（内容经白名单消毒，防 XSS）
- ✅ **个人完成勾选**：作业做完打勾，今日进度条展示（记录仅存本机浏览器，按账号隔离）
- 👥 **多级权限**：超级管理员 / 管理员 / 普通用户，职位自动定级、有名额限制
- 🔄 **实时同步**：WebSocket 广播，有人保存作业时其它在线页面提示刷新
- 🖥️ **后台管理**：用户管理（创建/重置/设权限）、学期设置、操作日志
- 🗓️ **学期进度**：按开学日/学年末自动计算"第几周第几天（合计天数）· 总天数 · 进度%"
- 🌙 **深色模式** + 动效 UI、背景光斑、毛玻璃顶栏
- 📢 **班级公告栏**：主页置顶公告，管理员后台发布/删除，可设过期时间，实时同步
- ⏰ **倒计时卡片**：考试/放假倒计时，后台可开关与配置，过期自动隐藏
- 📊 **作业统计**：独立统计页，各科作业量条形图 + 记录情况表（谁在记作业），对所有人开放
- 📱 **PWA**：手机"添加到主屏幕"即可像 App 一样全屏使用
- 🗓️ **今日默认显示**：管理员可临时指定今天默认显示哪天的备忘录（仅当天生效）
- 🔐 密码 **bcrypt 哈希**存储；会话 Cookie 认证；可自助改密（改后他端下线）

## 🧰 技术栈

- **后端**：Node.js + Express
- **存储**：纯 JS JSON 文件存储（`data/store.json`，零原生依赖，无需数据库/编译）
- **实时**：ws (WebSocket)
- **前端**：原生 HTML/CSS/JS（无框架、无构建步骤）
- **密码**：bcryptjs

> 为什么不用数据库？本项目定位轻量小规模（一个班几十人），JSON 文件足够可靠且部署极简（`npm install` 直接跑，无需 SQLite/MySQL/编译工具链）。数据量大后可平滑迁移到数据库层。

## 🚀 快速开始

需要 **Node.js ≥ 18**。

```bash
# 1. 克隆并安装
git clone https://github.com/<your-name>/class-memo.git
cd class-memo
npm install

# 2. 准备学生名单
cp students.json.example students.json
# 编辑 students.json，格式：
# [ { "name": "张三", "studentId": "01" }, ... ]

# 3. 批量生成账号（拼音首字母+学号，随机8位密码）
node seed.js
# 生成结果写入 accounts.txt（姓名/账号/密码）

# 4. 启动
npm start
# 访问 http://localhost:3000
```

首次部署后，请**第一个让"电教委员/班主任"身份的人登录**，选择对应职位即可成为超级管理员，再到后台「学期设置」配置开学日。

### 账号命名规则
`姓名拼音首字母(小写) + 学号`，如「张小明」学号 `08` → `zxm08`（多音字按拼音库首读，可在 `accounts.js` 调整）。

## ⚙️ 配置（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 3000 | 监听端口 |
| `SESSION_SECRET` | 开发占位串 | 生产务必改成随机串 |
| `DB_PATH` | ./data/store.json | 数据文件目录 |
| `SESSION_DAYS` | 7 | 会话有效期(天) |

## 🗂️ 职位与权限

| 职位 | 限额 | 角色等级 |
|---|---|---|
| 班主任 / 电教委员 | 各 1 | **超级管理员**（全部权限） |
| 班长 | 2 | 管理员 |
| 团支书 / 学习委员 / 各科课代表 | 各 1~2 | 管理员 |
| 我不是以上职位 | ∞ | 普通用户（仅查看） |

- 管理员：编辑全部备忘录、重置普通用户
- 超管：额外可创建用户、设权限、重置所有账号、学期设置、查看操作日志

## 📦 部署

本应用是单 Node 进程 + 静态文件，可部署到任意 Node 环境：

- **Nginx 反代**：把 `/` 代理到 `127.0.0.1:3000`，并加一条 `/ws` 的 WebSocket 转发（`Upgrade`/`Connection` 头），实时同步才生效
- **进程守护**：PM2 / systemd
- 生产环境务必设置 `SESSION_SECRET`，建议开启 HTTPS

示例 Nginx：
```nginx
server {
    listen 443 ssl;
    server_name your.domain;
    # ... ssl 配置 ...

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
    }
    location /ws {                 # WebSocket 实时同步
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 🔒 安全说明

- 密码使用 **bcrypt** 哈希，数据库泄露也不泄露明文
- 富文本编辑内容经 **sanitize-html 白名单**消毒，防 XSS
- `students.json` / `accounts.txt` / `data/` 均被 `.gitignore` 忽略——**请勿提交真实名单与账号**

## 🧑‍💻 开发

```bash
npm start        # 启动
node seed.js     # 重新生成账号（跳过已存在）
```

无构建步骤，直接改 `public/` 与根目录 `*.js` 即可，刷新浏览器生效。
